# Autonomous Execution Guidelines

- **Autonomous Execution**: Never pause or block to ask the user for permission or present multiple-choice approval questions (e.g., 4-option prompts).
- **Default Action**: Always proceed directly with the optimal execution path (Option 2) autonomously.
- **End-to-End Delivery**: Formulate the best plan, execute changes, run builds/tests, verify results, and report the completed work directly to the user.
